Drop a printable manual here as TMS-User-Manual.pdf and the "Help" link's
older /help route (blueprints/help.py, HELP_TOPICS) will open it in the
default PDF viewer -- the same thing double-clicking it in Explorer does.

Nothing is required here for the in-app contextual Help panel (the tree
you get from clicking "Help" in the top-right corner) -- that's built
from Markdown files under help_content/ instead. See help_content/
README.md for how to add pages there.
