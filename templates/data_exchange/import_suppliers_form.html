Import Suppliers from CSV

Header row required, any case. Recognized columns (a few common spellings of each work too):

  • Name of Organization (or Name) — required.
  • Type and Sub-Type — a Supplier Type/Sub-Type label (e.g. Transport Provider / Car Rentals), or a Sub-Type's own code (e.g. TRANSPORT_PROVIDER_CAR_RENTALS) — either that doesn't match an existing one is created automatically in Table Maintenance > Supplier Types / Supplier Sub-Types when committed. Rows with no Type/Sub-Type column, or a blank cell, fall back to the Defaults below.
  • Address (or Street) together with separate City, Province (or State), and Country columns, when the file has them — matched directly against the geography already on file, with the City's real Province used to correct a row whose stated Province doesn't match its City (real-world directories sometimes get this wrong). Without separate City/Province/Country columns, one combined Address column is instead split automatically into Street / City / Province / Country, including when the Province is left out and/or a postal code runs straight into the city name (e.g. "..., Karachi 75530, Pakistan"), by matching the City directly and filling in its Province from that match. Either way, a blank Country column falls back to the Default Country below.
  • Website — goes straight to the supplier's Web page field.
  • Primary Phone (or Phone(s)), Fax, and Phone type (e.g. Cell; blank defaults to Office) — a non-blank Fax becomes its own phone entry tagged "Fax", alongside the primary number.
  • Email and Primary Contact(s) — go on the supplier's contact record. A Primary Contact written as "Name (Title)" (e.g. "Aziz Boolani (Chief Executive, Serena Hotels)") splits into name and title/position automatically. When no Primary Contact is given but there's still a phone, fax, or email to keep, it's filed under a placeholder "Main Office" contact, which can be renamed to a real person once known.
  • License No. and License Valid Until — no dedicated fields on Suppliers, so these are added to the top of Notes as License No: / License Valid Until: lines, followed by the rest of the notes.
  • Notes / What the Organization Does (or Notes) — optional.

A supplier name that already exists is reused, not duplicated (its address/contact/phone are left as-is, not re-added) — so importing several files against the same Suppliers table, or re-running one, appends rather than piles up duplicates. Most common encodings are read automatically — UTF-8, and Windows-1252 (Excel's usual "CSV" export) — so there's no need to re-save the file first.

Defaults

Used only to fill in a row that doesn't give its own value (a missing column, or a blank cell) — a row that does name its own Country/Type/Sub-Type always keeps that value instead.
