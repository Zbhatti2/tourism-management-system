Import Services from CSV

This creates real entries on your Services list (Inventory Management → Services) — one per Sub-Group in the file, each with its own real, sequential Service Code. That's different from Import Service Codes from CSV, which only defines/updates the Category/Group/Sub-Group vocabulary itself (in Service Code Maintenance) without creating any catalog entries — if you've already run that one on this file, you can run this one on the very same file next to actually populate your Services list from it.

Header row required, any case. Recognized columns (same "Service Codes Bible" shape):

  • Category Code, Category Name
  • Service Code — Category-Group-Subgroup-Sequence form, e.g. TP-MN-MC-0001. Its Category/Group/Sub-Group segments must already exist in Service Code Maintenance — a code that isn't there yet is rejected, with a note to import the taxonomy first. The sequence digits themselves are ignored; your own next free sequence number is assigned automatically, same as creating a Service by hand.
  • Description of Code — becomes the new Service's Description. Left blank, the Sub-Group's own description (in Service Code Maintenance) is used instead.
  • Validity — not used here (only the taxonomy importer syncs it); a row whose Sub-Group is currently Deprecated is rejected outright, since a new Service can't be issued against a retired code.

A Sub-Group that already has a Service in your catalog (any status) is reused, not duplicated — safe to re-run. A brand-new one is created as Draft (bulk-generated starting points, not reviewed or priced yet) — open each from the Services list to fill in pricing/notes and flip it Active when it's ready.
