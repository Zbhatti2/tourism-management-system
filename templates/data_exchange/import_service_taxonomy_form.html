Import Service Codes (Taxonomy) from CSV

For the Category / Group / Sub-Group taxonomy behind every Service Code — updates Service Code Maintenance only. This does not add anything to your Services list (Inventory Management → Services) — for that, use Import Services from CSV instead (the same file works for both; run this one first if the codes aren't in Service Code Maintenance yet).

Built to read the "Service Codes Bible" export format directly. Header row required, any case. Recognized columns:

  • Category Code — required, e.g. TP.
  • Category Name — used only if that Category Code doesn't exist yet.
  • Service Code — required, Category-Group-Subgroup-Sequence form, e.g. TP-MN-MC-0001 (the sequence digits are ignored — actual sequence numbers are assigned per-tenant when a Service is created, not by this file).
  • Description of Code — required; read as "Category label — Group label, Sub-Group label" to derive the Group/Sub-Group name when creating a brand-new one.
  • Validity — required: Active, Under Review, or Deprecated.

A Category/Group/Sub-Group Code that already exists (matched case-insensitively) is reused, never duplicated — re-uploading the same Bible file after it was already committed is safe. For a Code that already exists, only its Description and Validity are refreshed from the file; its Name is left alone (renames go through Service Code Maintenance's own Edit screen, same "Code is immutable" rule as everywhere else in that module). A brand-new Code is created outright, with Name/Description as derived above. Most common encodings are read automatically — UTF-8, and Windows-1252 (Excel's usual "CSV" export).
