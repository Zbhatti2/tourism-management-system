Import Organizations from CSV

Header row required, any case. Recognized columns (a few common spellings of each work too — e.g. Name of Organization for Name, Phone(s) for Phone):

  • Name — required.
  • Type — an organization type code (e.g. BANK, SOCIETY) — one that doesn't exist yet is created automatically in Table Maintenance > Organization Types when committed.
  • Address — optional; split automatically into Street / City / Province / Country on the new organization's address (tagged "Mailing Address"), matching City/Province/Country against the geography already on file where possible. Any phone number(s) run into the Address text with no field of their own (e.g. "..., Columbus, Ohio 43210 United States of America, (419) 535-6794") are pulled out and used to fill in Phone when that column is blank. The Address column's original text is kept as-is on the organization record either way, as a fallback.
  • Phone, Email, Website, Notes — optional.
  • Primary Contact(s) — optional; folded into Notes, since organizations don't have a separate contact-person field.

A name that already exists is reused, not duplicated (the rest of that row is not applied on top of it). Most common encodings are read automatically — UTF-8, and Windows-1252 (Excel's usual "CSV" export) — so there's no need to re-save the file first.
