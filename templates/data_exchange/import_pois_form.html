Import Points of Interest from CSV

Header row required, any case. Recognized columns (a few common spellings of each work too):

  • POI Name (or Name) — required.
  • Type — a POI Type (e.g. Museum, Historical / Architecture) — one that doesn't exist yet is created automatically in Table Maintenance > POI Types when committed.
  • Country, City, Province/State — matched against the geography already on file where possible (linked automatically); a province or city not yet on file is kept as free text instead, same as typing it directly on the POI form.
  • Address — optional; goes on the POI's Local Location field.
  • Phone, Website — optional.
  • Notes — optional; goes on Historical Significance (that's what this column's content usually is — background on the site, not an internal note).
  • Email — optional; there's no separate email field on Points of Interest, so this is captured into Notes instead.

A POI name that already exists is reused, not duplicated (the rest of that row is not applied on top of it). Most common encodings are read automatically — UTF-8, and Windows-1252 (Excel's usual "CSV" export) — so there's no need to re-save the file first.
