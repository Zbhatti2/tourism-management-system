How to name the files

Put the photos in one folder and Zip it. Photos can arrive by WhatsApp, email or anything else; only the file names matter.

Each file name must start with the exact Hotel / Restaurant name, followed by a hyphen -. Whatever comes after the hyphen becomes the photo's suggested Title.

File nameGoes toSuggested Title
Hilton Hotel-Lobby at night.jpgHilton HotelLobby at night
Hilton Hotel-Pool.jpgHilton HotelPool
Hilton Hotel-1.jpgHilton HotelHilton Hotel — photo 1
Pearl-Continental Hotel Lahore-Ballroom.jpgPearl-Continental Hotel LahoreBallroom
  • Capitals, accents and underscores don't matter (avari_hotel_lahore-pool.jpg works).
  • A name that is almost right (Avary Hotel Lahore-…) is suggested but marked Check match.
  • A photo that's already in the album, or appears twice in the Zip, is marked Duplicate.
  • .jpg, .png, .webp, .gif, .tif and .heic; up to {{ 1000 }} photos per Zip.
