How to name the files

Put the photos in one folder and Zip it. Photos can arrive by WhatsApp, email or anything else; only the file names matter.

Each file name must start with the exact {{ what }} name, followed by a hyphen -. Whatever comes after the hyphen becomes the photo's suggested Title.
