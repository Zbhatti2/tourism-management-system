System Management covers administrative tools for the tenant as a whole
— most of it restricted to Tenant Admins.

## What's here

- **Change password** — for your own account.
- **System health** — a quick check page for the database and app state.
- **Audit log** — a record of who did what, with the ability to archive
  older entries to a downloadable file and set retention/purge rules for
  how long detailed history is kept.
- **Host organization** — your own tenant's organization record, with its
  own addresses and phone numbers, separate from the Organizations
  module's records for outside companies.
- **Backups** — create a backup on demand, download an existing one,
  restore from one, or delete one. Restoring is a significant, tenant-wide
  action — make sure you're restoring the right backup before confirming.

## Who can see this

Most of System Management is behind a Tenant Admin check — if a link
here 403s, that's expected for a non-admin account, not a bug.
