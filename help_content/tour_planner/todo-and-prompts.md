Each user has their own **To-Do List** and **Prompt List** for Tour Design.
Nobody else sees them.

## To-Do List

The **To-Do** button beside Help, on every Tour Design page, opens your list.
The badge on it shows how many tasks are still open.

- Type a **Subject** and a **Task**, then click **Add**.
- Inside a Tour Design, the Subject starts as the design's name and the task
  is linked to that design. **Only this design** shows just its tasks. A
  task from another design shows a link to it.
- Click **Open** to mark a task **Closed**, and click it again to reopen it.
  Click the ✕ to delete a task.
- Filter by subject or status (Open only, the default; Closed only; or all),
  and sort by **Date**, **Subject** or **Open/Closed**. The arrow button
  reverses the order.

## Prompt List

**Tours Management → Prompt List** keeps the prompts you write for the Tour
Design agent. The list shows each prompt's **Group**, **Title** and **Date
last used**, and how many times it has been used. You can search the list,
filter it by group, and sort it.

- **Open** a prompt to read it or improve it. Then:
  - **Save** keeps your changes in the same prompt.
  - **Save as new prompt** leaves the original as it was and saves your
    version as a new prompt. If you didn't change the title, the new one
    gets "(2)" after it.
  - **Delete** removes the prompt from your list.
- **Copy** puts the prompt on the clipboard to paste elsewhere.
- **Use** (or **Use for a new Tour Design**) starts a new Tour Design with
  the prompt as its request, and **Read the request into a brief** then
  points the agent at it. On the **New Tour Design** page you can also pick
  any of your prompts from **Start from one of my prompts**. You can change
  the request there; your saved prompt stays as it is.
- Copying a prompt or using it to start a design sets its **Date last
  used**.
- **Groups** are the same as your Package Groups (Table Maintenance →
  Package Groups).
- Your list starts with a sample prompt for a complete tour plan, the
  Karakoram Tour. Use it as a model for your own prompts.
