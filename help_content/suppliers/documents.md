Every Supplier has its own **Documents, Links and Images** card on its
view page — a place to keep copies of business licenses, permits, rules
and regulations, agreements, and photographs, all scoped to that one
supplier.

## Adding a document

Click **+** on the Documents, Links and Images card. A document has:

- **Document name** (required) and **Document type** — a Table
  Maintenance-managed lookup (Business License, Permit / Permission,
  Rules & Regulations, Agreement, Image / Photograph, Other).
- **Author(s)**, **Description** (up to 200 characters), and **Notes** —
  web URLs typed into Notes are automatically turned into clickable
  links.
- **Keywords** and **Hashtags** — comma-separated tags you can search or
  scan by later.
- **Cloud Link** and **Local Drive Path** — fill in either or both right
  on this form; each becomes its own location entry once you save. Use
  **Browse…** to pick a local file with the native file picker instead of
  typing the path.

A document can have more than one location (say, both a scanned local
copy and a cloud backup) — add more, or remove one, from the document's
own page after saving.

## Bulk Import Images

For adding several photographs at once, use **Bulk Import** instead of
adding them one at a time:

1. Click **Select Images…** to open a native multi-select file dialog —
   Ctrl/Shift-click to pick several files in one go.
2. Each file gets its own editable name in the list; adjust any of them
   before importing.
3. A shared **Document type** (defaults to "Image / Photograph") and
   **Notes** apply to every image in the batch.
4. Click **Import** — one Document is created per selected file, each
   with a Local Drive Path location pointing at that file.

## Why this exists

Per Zeb's original request, this mirrors the "Documents" reference form
under Organization Intelligence, minus Knowledge Domains and the Contacts
Link sub-feature — those didn't apply to a per-supplier record the way
they do to the tenant-wide knowledge base.
