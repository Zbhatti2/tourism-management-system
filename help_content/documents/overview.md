Documents (under **Organization Intelligence**) is a tenant-wide,
unattached knowledge base — files, links, and notes that aren't scoped to
any one Supplier or Organization record.

## What's on a document

- **Details** — document name, type, author(s), description, and notes
  (web URLs in Notes are auto-linked).
- **Locations** — any number of Cloud Link or Local Drive Path entries
  per document, the same shape used by Suppliers' own Documents, Links
  and Images sub-module.
- **Keywords and Hashtags** — comma-separated tags for search.
- **Knowledge Domains** and a **Contacts Link** sub-feature — tenant-wide
  concepts that don't apply to the per-supplier or per-POI versions of
  this pattern (those were deliberately left out there, since they were
  out of scope for a single supplier's or point of interest's own
  licenses/permits/images).

This is the reference form the per-supplier Documents, Links and Images
sub-module (and the newer per-POI Images/Links features) were both
modeled on.
