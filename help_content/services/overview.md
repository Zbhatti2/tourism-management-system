Services is one of the two catalogs under **Inventory Management** (the
other is Products) — the non-physical line items a Package can be built
from: guided tours, transfers, entrance fees, and the like.

## Service codes

Every service is classified against the tenant-wide **Service Taxonomy**
— a structured code list maintained in Tables & Utilities → Service Code
Maintenance. Classifying services consistently is what lets Packages,
reporting, and search treat similar services the same way across
suppliers.

## What's on a service record

Core details (name, description, pricing-relevant notes) plus its
Service Taxonomy classification and tenant-scoped catalog status. See the
Service Code Maintenance section of this help panel for how the taxonomy
itself is managed.
